# Text report

## When to use

- `mode=analysis`: full report is the only UI artifact
- `mode=both`: report explains the chart/data (rendered below the chart)

## Instructions

1. Base claims on data that was (or will be) loaded from allowlisted objects only.
2. Use plain language; include units, time grain, and caveats when relevant.
3. For `both`, explain what the chart shows — do not ignore the visual.
4. Do not invent numbers that were not computed from the data.
